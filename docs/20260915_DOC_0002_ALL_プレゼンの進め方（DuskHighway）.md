## 1. 1分版（エレベーターピッチ）

> 日没後の砂漠のハイウェイを走る、スマホ向けの3Dレースゲームです。
> 操作は画面を左右になぞるだけ。対向車を避けて、コインを集めて、ニトロで加速します。
>
> ねらいは **「単一HTMLで3Dゲームが成立するか」の実証** です。
> 3Dモデルもテクスチャも1つのHTMLに内包して、通信なしで動きます。約1.9MBです。
>
> 難易度3段階、6車種、ミッション、走るほど夜が明けていく時間帯の変化で、「もう1回」を作っています。
> Web版は公開済み、PWA対応済み。iOS化は他のアプリより実機検証に時間がかかるので、順番は後ろでよいと思っています。

### 2-1. 何のアプリか・ねらい（30秒）

- 3Dのエンドレスレース。縦持ち・片手
- ねらいは「うちの作り方（単一HTML・通信なし）で3Dまで作れる」ことを示す1本
- Web版は完成して公開中。PWA対応済み

### 2-2. デモ（3分）※台本

**① タイトル画面（30秒）**
> 「難易度は3段階。ツーリング・スポーツ・エキスパートで、障害物の量と速度、車体の数が変わります。車は6種類で、コインを貯めて解放します」
> （車を左右に切り替えて見せる）「速度・旋回・耐久が違います」

**② 走る（1分30秒）**
> （走り出す）「操作はこれだけです。左右になぞる。対向車とパイロンを避けます」
> 「コインを10枚取るとニトロが溜まる。右下のボタンで加速します」（ニトロを使う）
> 「ギリギリで抜けるとコンボが伸びてスコアが跳ねます。ミッションが毎回3つ出るので、『今回はこれを狙う』ができます」
> ※ 1,300mごとに空が変わる。届かなければ「走り続けると日没→薄暮→深夜→夜明けと変わります」と口で補足

**③ ゲームオーバー（30秒）**
> 「車体が0になると終了。ハイスコアは難易度ごとに記録されます。コインは貯まっていくので、次の車のためにもう1回、という流れです」

**④ 機内モード（30秒）※必ず見せる**
> （機内モードにして起動し直す）「3Dモデルもテクスチャも全部HTMLの中にあるので、**通信なしで動きます**。サーバーも外部ファイルもありません」

### 2-3. 技術と素材（30秒）

- Three.js で描画。3Dモデルは Kenney Car Kit（CC0・商用可・クレジット不要）。ライセンス全文を同梱
- モデルはコマンド1つで差し替えられる。差し替え手順は `MODELS.md` に文書化済み
- Claude Artifact ではテクスチャの読み込みが遮断される問題があったが、読み込み方法を差し替えて解決済み

### 2-4. 現状（30秒）

- Web版 完成・公開中、PWA対応済み。通信なし・端末内保存（ハイスコア・コイン・解放した車）
- 縦持ち固定。ブラウザで横にしてもHUDを縮小して対応

### 2-5. 次のステップとお願い（30秒）

- iOS化は Capacitor で半日（コツコツの `ios-app/` が雛形）。ただし **実機検証に2〜3日**：初回読み込みの体感、フレームレート、発熱
- 費用は Apple Developer Program（年12,800円）だけ。3Dモデルは CC0 でライセンス料なし
- **お願いしたいこと**：iOS化の順番は麻雀・語彙道場の後でよいか。実機検証にiPhoneを1台借りられるか

## 3. 想定質問と答え

| 質問 | 答え |
|---|---|
| 初回の読み込みが遅いのでは？ | 約1.9MBを読むので初回15〜20秒。起動画面は出る。PWA・iOS版はキャッシュ／内包されるので2回目以降は速い。ここは実機検証の主題 |
| 3Dモデルの権利は？ | Kenney Car Kit 3.1。CC0（パブリックドメイン相当）で商用可・クレジット不要。ライセンス全文を `models/` に同梱 |
| モデルを自社のものに差し替えられる？ | `node tools/embed-glb.mjs models/xxx.glb` の1コマンド。CC0素材・AI生成・Blender の3ルートを `MODELS.md` に書いてある |
| 電池・発熱は？ | 3D描画なので他のアプリより消費は大きい。実機検証で確認する項目 |
| なぜ縦持ち？ | 片手で信号待ちに遊ぶ想定。横持ちは manifest で固定を外せば対応できる |
| データは？ | 端末内のみ（ハイスコア・コイン・車）。通信ゼロ。App Store のプライバシーは「収集しません」 |
| 審査4.2（WebViewだけのアプリ）は？ | 完全オフライン・端末内保存・継続利用（コインと解放）。iOS化時に触覚を Capacitor Haptics に置き換える |
| Android は？ | Web版（PWA）がそのまま動く。ストア配布が必要なら Capacitor で Android も生成できる |
| 課金や広告は？ | なし。コインはゲーム内で貯めるだけ |

## 4. 話し方のコツ

- 最初の30秒で「3D」「通信なし」「操作は左右だけ」の3点を言い切る
- デモは**実際に走らせる**。スライドは補助
- 「ニトロ」と「機内モードで動く」の2か所は必ず見せる。時間帯の変化は届かなければ口で補足
- 数字は3つまで（1.9MB／6車種／3段階）
- 弱点（初回読み込み・実機検証の時間）は先に自分から言う。あとで指摘されるより印象がよい
- 最後は「お願いしたいこと」を具体的に言って終わる
